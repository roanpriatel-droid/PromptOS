Verify by visiting `/bundles/everything`, clicking Add to cart, applying `LAUNCH` in the cart drawer. Total should drop from $798 → $678.30.

A snapshot branch `store-pre-v3.8a-snapshot` was created locally at the pre-merge `main` commit before the v3.8a branch was opened. To revert the entire ship:

```bash
git checkout main

git push origin main --force-with-lease
```
